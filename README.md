# Raajsi Admin Dahboard
Raajsi Admin Dashboard
The administrative command center for the Raajsi E-commerce platform. This dashboard allows administrators to manage products, categories, orders, user data, and site-wide configurations through a modern, responsive interface.

🚀 Tech Stack
Framework: React 18 with Vite
Language: TypeScript
UI Components: Radix UI & Shadcn/UI
Styling: Tailwind CSS with tailwindcss-animate
Data Fetching: TanStack React Query & Axios
State Management: React Context API & Hooks
Forms: React Hook Form + Zod Validation
Tables: TanStack Table (Data Grid)
Icons: Lucide React & Tabler Icons
Editor: React Quill (Rich Text)
✨ Features
Inventory Control:
Comprehensive Product Management (Add, Edit, List).
